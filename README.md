# Task Manager

A simple responsive task management app built with HTML, CSS and JavaScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by All, Pending and Completed
- Clear completed tasks
- Save tasks with LocalStorage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to run

Open `index.html` in a browser.

## Project goal

This project demonstrates DOM manipulation, events, arrays, objects, functions, conditions and browser LocalStorage in vanilla JavaScript.
